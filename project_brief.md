# My agent: travel-planner
One-liner: A conversational agent that helps travelers assemble a personalized itinerary and illustrates each destination with generative visuals.

Tool coverage:
- Memory: Remembers traveler preferences (budget, travel pace, dietary restrictions, favorite activities, past trips)
- Tools: Look up destination activities, points of interest, weather, and assemble daily itinerary schedules
- Catalog/UI: Curated collection of destination landmarks, hotels, and attractions rendered as cards/tables (A2UI)
- Image gen: Generates custom postcard illustrations and travel mood boards for each destination
- Sandbox: Calculates budget estimates, trip duration splits, and currency conversion

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for itinerary time and budget calculation, Google Maps lookup
